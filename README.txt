AUBURN COVE — ADMIN PORTAL UPDATE

1. Open your GitHub repository benobiwanless/auburncove.
2. Upload portal.html, portal.js and portal.css from this folder to the repository root, replacing the existing three files.
3. Commit the changes and allow GitHub Pages to publish.
4. Open https://benobiwanless.github.io/auburncove/portal.html and refresh.
5. Test with a SECOND, unapproved test account before using confidential HOA documents. Confirm it cannot list, open, or download PDFs; then approve it and test again. Revoke it and verify access is blocked.

This update preserves the original Supabase project and security policies. It does not change your public homepage.

Security note: signed PDF links are valid for up to 60 seconds after creation, even if access is revoked during that interval.

Deleting a document removes its storage file first and its listing second. If listing deletion fails, an administrator will see an error and may need to clean up the orphaned listing.
